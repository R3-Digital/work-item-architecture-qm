## Register in QM Admin

In QM Admin → Skills, register this git repo URL:

`https://github.com/R3-Digital/work-item-architecture-qm`

Point registration at the folder that contains `SKILL.md` if the UI asks for a subdirectory (`skills/work-item-architecture`).
